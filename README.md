# Igreja Renascer em Cristo — Mogi das Cruzes

Static pre-launch institutional concept for review by Pastor Ronaldo.

## Preview locally

```bash
python -m http.server 4173
```

Open `http://localhost:4173/`.

## Content status

The WhatsApp number and client name are confirmed inputs. Address, schedule, visit guidance, social accounts, email, imagery, and other institution-specific information intentionally remain unpublished pending client confirmation.

## Files

- `index.html` — semantic page structure and Portuguese copy
- `styles.css` — responsive visual system and accessibility states
- `script.js` — mobile navigation behavior
- `assets/fonts/` — self-hosted Bricolage Grotesque font and OFL license
- `PRODUCT.md`, `DESIGN.md`, `.impeccable/` — product and design context
